## Protocol

[![crates.io-core][crates.io-core-badge]][crates.io-core] [![docs.rs-core][docs.rs-badge]][docs.rs-core]
This crate contains internal protocol information for the Benthic project. These protocols are not the open metaverse protocols, but contain specs for messages sent to and from the core, the server, and the UI, along with common structs used by both the messages crate and the simplified benthic protocol.
